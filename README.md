## Presentation Principles

1. **Simple to look at, simple to explain, technically strong underneath.**
2. **One idea per slide, one dominant visual.**
3. **No persistent headers, no footers, no slide badges.**
4. **Academic serif typography:** Georgia headings, Times New Roman body, Courier New code.
5. **Restrained color palette:** Navy primary (`#0F2038`), warm off-white background (`#FAFAF8`), subtle orange accent (`#D9531E`), light gray structure (`#E2E8F0`), green intact (`#16A34A`), amber anomaly (`#D97706`), red tampered (`#DC2626`).

## Navigation Controls

- `Right Arrow` / `Space`: Next slide
- `Left Arrow`: Previous slide
- `F`: Toggle Fullscreen
- Keyboard navigation is active by default.
